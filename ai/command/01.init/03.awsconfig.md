

# Load configuration from AWS secret manager


Use aws chain method, load from server user first, or try load from local AWS profile first, profile name "secman-los-dev".

Secret name is "secman-los-uat", value is in JSON.

Create typescript type under shared/types/configuration.d.ts, make it public.

Load configuration when application started, and only refresh every one hour, don't read from AWS every time.

Configuration should only available for server side. Frond end will not have access.

Create backen method to test. GET /api/get-configuration, it will return configuration object.
